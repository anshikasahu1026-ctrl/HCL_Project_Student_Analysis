# Student Performance and Attendance Analyzer

## Project Overview
A simple Student Performance and Attendance Analyzer developed using Python and Pandas. The project analyzes student academic performance, quiz marks, lecture attendance, lab attendance, and assignment data.

## Objectives
- Load and analyze student data from a CSV dataset.
- Display student records.
- Calculate class averages for midterm marks, final marks, and previous GPA.
- Analyze quiz marks and calculate quiz averages.
- Find the top 5 students based on final marks.
- Analyze lecture and lab attendance.
- Search for a student using their ID.
- Categorize students based on their final marks.
- Analyze assignment submission data.

## Technologies Used
- Python
- Pandas
- Google Colab
- CSV Dataset
- GitHub

## Dataset
Student Dropout Behavior Dataset obtained from Kaggle and used for analyzing student performance, quiz scores, attendance, GPA, and academic records.

## How to Run
1. Download the project repository.
2. Open `Student_Performance_Analyzer.ipynb` in Google Colab.
3. Upload the required CSV dataset.
4. Run the notebook cells.
5. Use the menu displayed to select the analysis you want to perform.
